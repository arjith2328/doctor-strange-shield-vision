# 🛡️ Doctor Strange Shield Vision

A **Doctor Strange-inspired Augmented Reality (AR) Shield** built using **Python, OpenCV, MediaPipe, and CVZone**. This project uses real-time hand tracking to generate an interactive magical shield effect through a webcam, inspired by the iconic visual effects from Doctor Strange.

> **Disclaimer:** This project is a fan-made educational demonstration inspired by the visual effects of Doctor Strange and is not affiliated with or endorsed by Marvel.

## 🚀 Installation

### 1️⃣ Clone the repository

```bash
git clone https://github.com/arjith2328/doctor-strange-shield-vision.git
```

### 2️⃣ Navigate to the project

```bash
cd doctor-strange-shield-vision
```

### 3️⃣ Install dependencies

```bash
pip install -r requirements.txt
```

Or install manually

```bash
pip install opencv-python mediapipe cvzone numpy
```

### 4️⃣ Run the project

```bash
python Doctor_Strange_Shield.py
```

---

## 🎮 How It Works

1. Open the webcam.
2. The system detects your hand using MediaPipe.
3. The animated shield follows your hand in real time.
4. Raise one or both hands to create the magical shield effect.
